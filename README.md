# Taquilla

Proyecto de curso: frontend de un sitio de eventos y boletería, hecho con Next.js
(App Router) y TypeScript. Los datos y los textos de la interfaz salen de la
[API de Taquilla](https://yanethm-taquilla-api.fly.dev/api/v1).

## Empezar

```bash
npm install
cp .env.example .env.local
npm run dev
```

Abre <http://localhost:3000>.
